# Electron 教程开发计划

## 结课能力覆盖

| 结课能力 | 核心知识 | 工程实践 | 章节 | 验收证据 |
|---|---|---|---|---|
| 启动桌面应用 | main、renderer、生命周期 | 创建安全 BrowserWindow | 01–02 | 应用窗口可启动 |
| 设计桌面能力边界 | preload、context isolation、IPC | 类型化 notes API | 03 | UI 可读写笔记且无 Node 全局 |
| 管理本地数据 | userData、文件 I/O、错误处理 | 原子化 JSON 存储 | 04 | 重启后数据仍存在 |
| 集成操作系统 | Menu、dialog、窗口状态 | 菜单命令和导入导出 | 05 | 菜单与对话框可操作 |
| 保障应用质量 | 安全清单、日志、DevTools | 输入验证与故障定位 | 06 | 检查命令通过且能定位注入错误 |
| 交付安装包 | Forge、asar、平台制品 | package/make | 07 | 生成可运行制品 |

## 阶段

1. 固定 Electron、Node.js、TypeScript 与构建工具版本，创建统一工程。
2. 串行完成七章正文和对应 demo 说明，每章单独验收。
3. 根据最终工程编写代码环境配置附录。
4. 集成课程导航、术语表和来源，执行全链路与 UI 验收。

## 分支边界

基础环境、各章节和最终集成是独立可审阅切片。每个切片使用独立分支和提交；章节按顺序建立在已验收前置分支之上，避免并行修改同一 demo。

## 完成标准

- 从干净检出执行安装、静态检查、自动验证、启动、打包均成功。
- 每章正文、代码说明和实际工程一致。
- Electron 安全与版本敏感结论均有官方来源。
- Windows 上完成界面与交互验证；其他平台差异明确标注为未在本机验证。
